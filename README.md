# Secure Incidents Tracker

## Descrição
Aplicação Full Stack desenvolvida para o registro e acompanhamento de incidentes digitais, simulando um ambiente corporativo com foco em segurança da informação e gestão de riscos.

## Objetivo
Aplicar conceitos de desenvolvimento Full Stack, organização de dados e noções de cibersegurança, por meio de um sistema educacional de controle de incidentes.

## Tecnologias Utilizadas
- Back-end: C# | .NET
- Front-end: React | TypeScript | HTML | CSS
- Banco de Dados: SQL Server
- Versionamento: Git | GitHub

## Funcionalidades
- Registro de incidentes digitais
- Classificação por tipo e nível de risco
- Acompanhamento de status
- Histórico de atualizações

## Contexto de Segurança
Projeto educacional sem dados reais, desenvolvido para estudo de boas práticas em segurança da informação.

## Status
Projeto em desenvolvimento para fins de aprendizado.
